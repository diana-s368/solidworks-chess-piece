# SolidWorks Chess Piece

## Overview

This project contains a custom 3D chess piece modeled in SolidWorks as part of a university laboratory assignment for the *Fundamentals of Logic Design* course.

The goal was to create a 3D model from a 2D sketch and practice fundamental CAD modeling techniques.

## Tools and Techniques

- **Software:** SolidWorks
- **Sketching:** Lines, rectangles, centerlines, splines, and circles
- **Modeling:** Revolved Base
- **Finishing:** Edge rounding and fillets

## Modeling Process

1. Created a 2D sketch representing half of the chess piece's profile.
2. Defined the base and upper section using dimensional constraints.
3. Used splines to create curved sides.
4. Revolved the sketch around a centerline to generate the 3D geometry.
5. Applied fillets to refine the base and upper section.
6. Reviewed the final model.
